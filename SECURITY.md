# Reporting security issues / 安全问题报告

Please do not open a public issue for a security problem in PassBy, and please keep the details private until it is fixed.

- Email <support@tenonai.cn> with "PassBy security" in the subject. We reply within one business day.
- Or use this repository's private "Report a vulnerability" on GitHub.
- Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled.

Include the affected version or commit, steps to reproduce and the impact you expect. Never include real passwords, keys, tokens or personal data, or real export codes and export files.

Fixes go into the latest release.

Scope: the iPhone app, the Android app, the export file format (`docs/export-format.md`) and the Wi-Fi sync protocol (`docs/sync.md`) in this repository, and the pages on passby.tenonai.cn, including the web version.

---

发现 PassBy 的安全问题，请不要开公开的 issue，也请在修好之前不要公开细节。

- 邮件：<support@tenonai.cn>，标题注明「PassBy 安全」，我们会在 1 个工作日内回复。
- 或者用本仓库 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的密码、密钥、令牌或个人数据，以及真实的导出码和导出文件。

修复只进最新发布的版本。

范围：这个仓库里的 iPhone 应用、安卓应用、导出文件格式（`docs/export-format.md`）和局域网同步协议（`docs/sync.md`），以及 passby.tenonai.cn 上的页面，包括网页版。
