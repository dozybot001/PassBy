# 安全问题报告 / Reporting security issues

发现 PassBy 的安全问题，请不要开公开的 issue。

- 邮件：<support@tenonai.cn>，标题注明「PassBy 安全」。
- 或者用 GitHub 的「Report a vulnerability」（私下报告）。
- 报告和答复的做法见榫卯 Tenon AI 的[安全政策](https://tenonai.cn/security/#report)。

请写明：受影响的版本或提交、复现步骤、你认为的影响。请不要在报告里放真实的密码、导出码或导出文件。

范围：这个仓库里的 iPhone 应用、安卓应用、导出文件格式（`docs/export-format.md`）和 passby.tenonai.cn 上的页面。

Please do not open a public issue for a security problem in PassBy. Email <support@tenonai.cn> with "PassBy security" in the subject, or use GitHub's private "Report a vulnerability". Tenon AI's [security policy](https://tenonai.cn/security/#report) describes how reports are handled. Include the affected version or commit, steps to reproduce and the impact you expect. Never include real passwords, export codes or export files.
