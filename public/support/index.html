Support

PassBy for Android is available; see “Verify the Android app” below. The earlier PassBy web app, which needed a Tenon account, was retired on November 15, 2026, and the iPhone version that synced through iCloud (1.3 and earlier) is no longer offered. The sign-in service is shut down; a notebook already on your iPhone still opens with Face ID or Touch ID. The sections after “Verify the Android app” are for people who already installed that earlier iPhone version.

PassBy is a simple password notebook. Store a title, account, password and notes, organize entries into folders, and generate random passwords.

Verify the Android app

The PassBy Android app is published only on the PassBy release pages on Gitee and GitHub; our website links to them. Before installing, you can check the installer's signature:

  • Package name: cn.tenonai.apps.passby
  • Signing certificate SHA-256: CDD81F2D2D37F3DB9C460C4F6E2186C900D6C68337589541284A683FD44A4984
  • How to check: on a computer, run apksigner verify --print-certs PassBy-<version>.apk (apksigner is in the Android SDK build-tools). The “certificate SHA-256 digest” line should match the value above; it is printed in lowercase, and the same letters and digits mean the same certificate.

If an update warns that the signature does not match, or asks you to uninstall the old version first, do not install it. Come back to this page and check where the installer came from. Uninstalling PassBy deletes the notebook that exists only on this phone; if you really need to switch installers, export first and keep your export code or passphrase.

PassBy on the web

The web page works with PassBy on your phone, in Chrome or Edge on a computer on the same Wi-Fi. In PassBy on the phone, open Settings › Sync and tap “Let another device connect”, then enter the address and pairing code it shows. The browser asks once to allow access to devices on your local network; allow it. If it cannot connect, check that both are on the same Wi-Fi and that the sync page is still open on the phone. The notebook is not stored in the browser, and it is cleared when you close the page. The earlier web app, which needed a Tenon account, was retired on 15 November 2026.

网页版要和手机上的 PassBy 一起用：电脑和手机连同一个 Wi-Fi，用 Chrome 或 Edge 打开。在手机的 PassBy 里打开「设置 › 同步」，点「让别的设备连过来」，把显示的地址和配对码输到网页里。浏览器会问一次是否允许访问本地网络上的设备，请选允许。连不上时，检查两边是否在同一个 Wi-Fi、手机上的同步页面是否还开着。浏览器里不保存密码本，关掉网页就清掉。需要 Tenon 账号的旧网页版已于 2026 年 11 月 15 日停用。

Contact Tenon support

Email support@tenonai.cn. Include “PassBy”, your iPhone model, iOS version, app version and the step that failed. Never send passwords, recovery keys, Apple verification codes or device passcodes. Send screenshots only after removing private information.

Apple Account

Use the Apple Account signed in to iCloud in iPhone Settings. The sign-in service is shut down. The notebook is encrypted on your device before syncing to your private iCloud database. Keep iCloud access enabled for PassBy.

Unlocking

PassBy requires an iPhone with a device passcode and Face ID or Touch ID enrolled. Whenever you leave the app, it locks. Screen recording or screen mirroring prevents unlocking. If Face ID or Touch ID is locked out, unlock your iPhone with its passcode first, then retry.

Recovering on a new iPhone

Sign in to the same Apple Account, install PassBy, and enter the recovery key you saved when creating the notebook. Face ID or Touch ID is also required. Keep this key outside PassBy. While a device still opens the notebook, Settings can show the key again after another Face ID or Touch ID check. Support cannot decrypt a notebook or replace a lost key.

Drafts and copying

Swiping down to close a new or edited entry keeps an encrypted draft on this iPhone. Open New password to resume it. Save stores the entry; Cancel discards the draft. Copied passwords expire after 60 seconds and do not use Universal Clipboard.

Sync and deletion

Settings shows sync status and offers Sync now. If iCloud is unavailable, edits remain encrypted locally and sync retries while the notebook is open. Cold launch requires confirming your iCloud identity. Delete entries and folders inside the app, then wait for sync to complete. Each iPhone keeps deleted passwords, including those deleted on another device, encrypted in Settings > Recently Deleted for 30 days; they are not synced. Uninstalling removes local files but does not remove the iCloud notebook.

简体中文

PassBy 安卓版已发布，见下面的「核对安卓安装包」。需要 Tenon 账号的旧网页版已于 2026 年 11 月 15 日停用，通过 iCloud 同步的 iPhone 版（1.3 及更早）不再提供。「核对安卓安装包」一节以下的内容，给已经装好旧版 iPhone 应用的人看。

核对安卓安装包

PassBy 安卓版只在 Gitee 和 GitHub 上的 PassBy 发布页发布，官网有链接。安装前可以核对安装包的签名：

  • 包名：cn.tenonai.apps.passby
  • 签名证书 SHA-256：CDD81F2D2D37F3DB9C460C4F6E2186C900D6C68337589541284A683FD44A4984
  • 核对方法：在电脑上运行 apksigner verify --print-certs PassBy-<版本号>.apk（apksigner 在 Android SDK 的 build-tools 里），输出里「certificate SHA-256 digest」一行应和上面的值相同。它打印的是小写字母，字母和数字一致就是同一个。

更新时如果系统提示签名不一致，或者要你先卸载旧版才能安装，请不要安装，先回到本页核对安装包是从哪里来的。卸载 PassBy 会删掉只存在这台手机上的密码本；确实要换安装包时，先导出一份，记好导出码或口令。

联系 Tenon 支持

邮箱：support@tenonai.cn。请注明 PassBy、iPhone 型号、iOS 版本、应用版本及出错步骤。不要发送密码、恢复密钥、Apple 验证码或设备密码；截图需先隐藏私人信息。

账号、解锁与恢复

登录服务已停用，已有的密码本仍可通过 Face ID 或 Touch ID 打开；密码本存储使用本机 iCloud 的 Apple 账号。密码本先在本机加密，再同步至 iCloud 私有数据库。设备需设置密码并登记 Face ID 或 Touch ID。离开应用后重新验证，录屏或镜像期间无法解锁。新设备需登录同一 iCloud 账号并输入创建密码本时保存的恢复密钥。请将密钥保存在 PassBy 之外，支持人员无法解密密码本或替换丢失的密钥。只要仍有设备能打开密码本，可在设置中再次通过 Face ID 或 Touch ID 后查看恢复密钥。

草稿与复制

下滑关闭新建或编辑页会将草稿加密保存在本机；点击“新建密码”可继续。保存会存入条目，取消会丢弃草稿。复制内容 60 秒后过期，不使用通用剪贴板。

同步与删除

设置页可查看同步状态并手动同步。连接失败时编辑保存在本机，密码本打开后会重试；冷启动需确认 iCloud 身份。在应用内删除条目和文件夹后，等待同步完成。每台 iPhone 会在“设置 > 最近删除”中加密保留已删除的密码 30 天（包括在其他设备上删除的），不会同步。卸载应用不删除 iCloud 密码本。
